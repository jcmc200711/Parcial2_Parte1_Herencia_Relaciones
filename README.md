# 🌱 Sistema de Facturación para Tienda Agrícola

Este proyecto consiste en el desarrollo de un sistema de facturación orientado a una tienda agrícola, el cual permite gestionar productos como fertilizantes, plaguicidas y antibióticos para animales (bovinos y porcinos).

Sistema desarrollado en Python utilizando Programación Orientada a Objetos (POO) para la gestión de productos agrícolas, compras, facturación e historial de clientes.

## Funcionalidades

 **Registro de productos:**
  - Fertilizantes
  - Control de plagas
  - Antibióticos (bovinos y porcinos)

 **Gestión de compras:**
  - Selección de productos por ID
  - Agregado de múltiples productos a una factura

 **Generación de facturas:**
  - Cálculo automático del total
  - Visualización estructurada

 **Validación de datos:**
  - Entradas numéricas
  - Cadenas de texto
  - Fechas
  - Multiples facturas asociadas a un solo cliente
  - Busqueda de facturas por cédula

Proyecto académico desarrollado para la Universidad Tecnológica de Pereira en la asignatura de Programación IV.
